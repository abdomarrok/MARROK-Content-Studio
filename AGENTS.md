# AGENTS.md

## Quick facts
- React 19 + TypeScript 7, Vite 8, Tailwind v4, Express (`server.ts` + `api/index.ts`), `@google/genai`; single npm package `marrok-content-studio`, no workspaces. Node `>=22` (`.nvmrc` = 22).
- Path alias `@/*` -> repo root (tsconfig + vite). HTTP flow: `server.ts` -> Express `api/index.ts` + Vite middleware (dev when `NODE_ENV !== 'production'`) or `dist/` static (prod). UI flow: `src/main.tsx` -> `src/App.tsx` (`AuthGateModal`, lazy modals) -> Phase 1 `src/components/AutonomousStudio.tsx` or Phase 2 `src/components/studio/PublishingHubWorkspace.tsx`.
- Shared types `src/types.ts`; palettes `src/lib/theme/palettes.ts`; feed color cadence `src/lib/theme/cadenceEngine.ts`. Five canvas presets (`tiktok-9:16`, `ig-4:5`, `ig-3:4`, `ig-1:1`, `ig-9:16`) and four post formats (`PostFormat = 'carousel' | 'single' | 'meme' | 'reel'`).

## Commands
- Install: `npm install` (`.npmrc` sets `legacy-peer-deps=true`; `package-lock.json` is the only lockfile).
- `npm run dev` — Express + Vite on `http://localhost:3000`, binds `0.0.0.0` (`PORT` overrides).
- `npm run lint` / `npm run typecheck` — both `tsc --noEmit`. `npm test` — Vitest (jsdom, `isolate: false`; 35 specs). Single file: `npx vitest run src/lib/qaAndRiskChecks.test.ts`; filter: `npm test -- <pattern>`; watch: `npm run test:watch`.
- `npm run test:e2e` — Playwright (`e2e/smoke.spec.ts`), auto-starts `npx tsx server.ts` on `:3000`, mobile 390px + desktop projects. Excluded from Vitest and not run by CI.
- `npm run build` — production bundle -> `dist/`. `npm run preview`, `npm run clean` as defined.
- `npm run start` — does **not** set `NODE_ENV`; without it it runs Vite middleware, not `dist/`. Production: `$env:NODE_ENV='production'; npm run start` (PowerShell).
- `npm run hash-password` — masked scrypt hash for `ADMIN_PASSWORD_HASH`.
- Before finishing run `npm run lint` + `npm test` (add `npm run build` for bundling/import regressions). CI (`.github/workflows/ci.yml`) runs install, lint, test, build on Node from `.nvmrc`.

## Auth & security gate
- Protected `/api/*` routes fail closed (`503`) until `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH` (scrypt), and `SESSION_SECRET` (>=16 chars) are set. Only `/api/health`, `/health`, and `/api/auth/*` are unauthenticated. Login sets `__Host-marrok_session`; clients may also send `Authorization: Bearer <token>` (iframe token in `sessionStorage` key `marrok_iframe_session_token_v1`). Local `.env` supplies these; Vitest tests set their own.
- Cron/webhook callers bypass the session only with `x-api-secret: API_SHARED_SECRET`; the Telegram webhook additionally validates `x-telegram-bot-api-secret-token` against `TELEGRAM_WEBHOOK_SECRET` (`src/lib/security/sessionAuth.ts`).
- CORS is a strict allowlist (`ALLOWED_ORIGINS` / `ALLOWED_ORIGIN` / `APP_URL` -> `src/lib/security/corsPolicy.ts`; wildcard `*` rejected; unknown Origin -> `403`). Server Gemini keys are only exposed to authenticated requests or a matching `x-api-secret`.
- Deploy previews/branch deploys reject mutating `/api/posts` and `/api/publish/*` unless `ALLOW_PREVIEW_WRITES=true` (`src/lib/security/env.ts`).

## Deployment & API surface
- Vercel (`vercel.json`): rewrites `/api/*` -> `/api/index`, SPA fallback `/(.*)` -> `/index.html`; `api/index.ts` restores the real path from `x-matched-path`/`x-forwarded-uri`. Preserve this.
- Netlify (`netlify.toml`): `/api/*` -> `/.netlify/functions/api/:splat`. Every function in `netlify/functions/` (`api`, `auth`, `posts`, `generate`, `publish`, `gather`, `proxy`) is a thin v2 wrapper delegating to the same Express app via `src/lib/network/netlifyBridge.ts`; `scheduled-promote.ts` promotes overdue scheduled posts and sweeps Cloudinary.
- Adding an `/api` route: register it in `api/index.ts` **and** in a Netlify function `config.path`. Path sets must stay disjoint and never use `/api/*` (`apiRouting.test.ts`). Keep the `/api/*` redirect ahead of the SPA fallback and never add `force = true` to the catch-all.
- `/api` may contain at most 12 files recursively (currently 11); enforced by `src/lib/network/apiRouting.test.ts` (Vercel Hobby limit + Netlify zip bundling). Don't add files there casually.
- Code reachable from `api/` or `netlify/functions/` must not import browser/canvas/IndexedDB modules; keep Node-only utilities standalone (e.g. `src/lib/publish/tiktokTitle.ts`).

## Source map / gotchas
- Barrels: `src/lib/synthesizer.ts` -> `src/lib/synthesis/`, `src/lib/canvasExporter.ts` -> `src/lib/canvas/`, `src/lib/textSanitizer.ts` -> `src/lib/text/`. Edit the modular files, not the barrels.
- `src/lib/canvas/` is the static + single-slide video pipeline. `renderSlide.ts` is a pure read-only projection (do not sanitize in the draw loop); `textLayout.ts` fits text. `constants.ts` holds the real safe zones: `SAFE_MARGIN_LEFT=84`, `SAFE_MARGIN_RIGHT=930`, `SAFE_MAX_Y=1650`, `SAFE_HEADER_Y=206`, `SAFE_FOOTER_CEILING_Y=1428`, plus `FULL_MEME_CARD_W=1008` and `resolveSmartFullMemeCardBounds()`. `layoutAwareness.ts` computes non-overlapping clearances (`MIN_GAP_GRAPHIC_TO_TITLE=44`, `MIN_GAP_TITLES=18`, `MIN_GAP_TITLE_TO_BODY=36`, `MIN_GAP_BODIES=22`, `MIN_GAP_TO_FOOTER=24`), font scaling, ceiling compression, and `clampElementDrag()`. `layoutBounds.ts` consumes it for 1:1 viewport overlays/hit-testing.
- `videoFrameExtractor.ts`: `extractVideoStoryboardDataUrl` (2x2 keyframes for Gemini Vision), `buildCleanMemeCarouselDeck`, `applySlideGraphicPhoto`, `analyzeImageForMemeAndCaption`. `singleSlideVideoExporter.ts` (`exportSingleSlideVideo`) muxes single-slide video with MARROK chrome + preserved audio (`.mp4`/`.webm`).
- `src/lib/theme/cadenceEngine.ts` (`analyzePostHistoryCadence`, `resolveHarmoniousPaletteWithoutRepetition`) reads posted Vault records (`postStatus === 'posted'`) to avoid consecutive same-color posts; `ThemeCustomizer.tsx` shows "Recommended Next Palette" and `AutonomousStudio.tsx` auto-rotates during synthesis.
- `src/lib/publish/publishClient.ts` + `api/controllers/publishController.ts` = Direct API publishing, calendar queue, TikTok Commercial Music, Cloudinary cleanup:
  - Signed SHA-1 Cloudinary staging (`uploadSlideToCloudinary` -> `marrok_staging/*`; ephemeral public HTTPS fallback without secrets) and cleanup (`destroyCloudinaryAsset`/`sweepExpiredCloudinaryAssets`) `+1h` after `postedAt`/scheduled `dueAt`.
  - Buffer GraphQL (`https://api.buffer.com`) for Instagram (`@marrok_org`; multi-slide uses `metadata.instagram.type: 'post'`), Facebook, LinkedIn.
  - Zernio REST v1 (`https://zernio.com/api/v1`, MCP `https://mcp.zernio.com/mcp`) for TikTok (`@marrokorg`, up to 35 `9:16` photo slides) and Instagram failover, with dual-aspect staging (`ig-4:5` 1080x1350 for IG/FB/LI + `tiktok-9:16` 1080x1920 for TikTok).
  - `GET /api/publish/tiktok-music` -> Zernio commercial music library (`autoAddMusic` + `musicSoundInfo`).
- `src/lib/motion/` is the 9:16 Motion Reel engine (from `abdomarrok/motion-reel`, fused with MARROK chrome): `base.ts` (spring/Mulberry32/easings/cues/wrapHTML), `marrokSlideChrome.ts`, 4 templates (`marrok-slides`, `kinetic-text`, `brand-intro`, `product-showcase`), `sfxSynthesizer.ts` (48kHz procedural SFX + PCM WAV), `carouselToReelConverter.ts`, `videoExporter.ts` (MediaRecorder + AudioContext -> `.webm`/`.mp4`, `.wav`, standalone `.html`).
- `src/components/studio/`: `ViewportCanvas` (instant render, external toolbar dock `viewport-external-toolbar-dock`, 150ms text debounce, auto `imageAspectRatio`, selection sync, collision-clamped drag, keyboard nudge), `InlineSlideEditor` (`syncSlideVisualFromText`, `fitSlideTextLimits`, meme vs graphic-photo workflows), archetype editors, `PublishingHubWorkspace.tsx`/`PostManagerPanel.tsx` (**Inbox -> Draft -> Schedule**, list/7-14d calendar/bulk schedule/publish now, mandatory `Human Reviewed` + `Claims & Numbers Verified`, `>2/day` warning), and `studio/motion/`.

Controllers in `api/controllers/`; prompts/schema in `api/prompts/systemPrompt.ts`; Postgres pool in `api/db/postgres.ts` (falls back to local `data/saved-posts.json` when offline).

## AI generation & publishing cascade
- `.env` keys: `DATABASE_URL` (or `POSTGRES_URL`/`NETLIFY_DATABASE_URL`/`..._UNPOOLED`), `GEMINI_API_KEY`, `GEMINI_API_KEY_BACKUP`/`_2`, `GEMINI_API_KEYS` (comma pool), Cloudinary, `BUFFER_API_KEY`, `ZERNIO_API_KEY`, Telegram, `ALLOWED_ORIGINS`, `APP_URL`, session/auth vars, `FREE_BACKUP_AI_ENABLED`, `RATE_LIMIT_RPM`, `GEMINI_*_MODELS`. See `.env.example`. Client Gemini keys: `x-gemini-key`/`x-gemini-api-key`, `x-gemini-backup-key`, body `apiKey`/`backupApiKey`; stored in `localStorage` as `marrok_custom_gemini_key` / `_backup`.
- `resolveRequestGeminiKeys` (`api/config.ts`): client primary -> client backup -> server primary -> server backup -> `GEMINI_API_KEYS`, deduped.
- `POST /api/generate` (`api/controllers/generateController.ts`): 45s budget with `AbortSignal.timeout()`; iterates Gemini keys (grounded when prompt <= 200 chars, then schema attempts); on all-key failure/quota cascades to zero-key Pollinations (`api/freeAiFallback.ts`, disabled by `FREE_BACKUP_AI_ENABLED=false`), then local `synthesizeCarousel()` (`engine: 'offline-synthesizer'`), never 5xx; sets `X-Marrok-Engine`/`X-Marrok-Model`.
- `POST /api/generate-image` (`GEMINI_IMAGE_MODELS`): defaults 9:16 / 1K, supports editing via `inlineData` (<= 4 MB). Pass only `imageConfig` (never `responseMimeType`/`responseSchema`). Falls back to 9:16 Flux text-to-image.
- `runAutonomousPipeline` only calls `sanitizeFullCarousel()` on authentic AI output; full character fitting/pacing/QA rewrite runs only for the offline fallback. Don't "fix" AI copy unless asked.
- `src/lib/synthesis/smartVisualDefaults.ts` + `bundledTechSvgs.ts`: `detectSubjectPairFromText()` picks `subjectPair` only for two verified distinct software/tech products in a migration/before-after (`resolveRealTechSystem`), names both in `layoutRationale`, and gates `creativeMotif: 'chat-to-db'` on messaging + storage. Other topics use topic-aware `row` schematics (`topology`, `stack`, `isolation`, `takeaway`, `scatter`, `graph`, `clusters`, `split`, `features`). `condenseCarouselToSingleSlide()` turns a deck into a 1-slide poster with 3 bilingual takeaways.
- Postgres (`api/db/postgres.ts`) is the durable vault (`saved_posts`, JSONB decks, indexed `post_status`/`scheduled_for`/`updated_at`/`title_signature`, idempotent init, `ON CONFLICT (id) DO UPDATE`), with local file + IndexedDB fallback.

## Content / export conventions
- Formats: `carousel` (3-10), `single` (poster / standard archetype / single-slide video), `meme` (1-slide standalone, `FULL_MEME_CARD_W=1008`, 6px padding, smart card hugging, no top-right category tag, Vision AI caption), `reel` (9:16 motion).
- Slide types: `hub`, `row`, `number`, `metric`, `code`, `compare`, `subjectPair`, `image`, `poster`, `cta`. Multi-slide slide 1 uses a Hook or `subjectPair`, never `hub` or empty `metric`. `subjectPair`: max 2 unedited bundled official SVGs (<= 14% slide width / 151px at 1080px), owner as text wordmark, required `"Not affiliated with <Company>"`, falls back to `row` if a brand is empty. Placeholder strings (`System A`, `System B`, `PIPELINE MIGRATION`, `DATASTREAM MIGRATION`) and empty brands are blocked from render/export (`qaChecks.ts`, `riskChecks.ts`).
- Keep bilingual `en*`/`ar*` populated unless `standaloneMeme`/`imageFrameMode === 'full'`; technical nouns stay English Latin script with BiDi isolation in Arabic (`checkArabicTranslatedTechTerms` warns).
- QA limits (`src/lib/qaChecks.ts`): `enTitle` 45 / `arTitle` 40 / `enBody` 140 / `arBody` 150 (hook slide: 55/50/220/230). Typography floors: >= 24px title/body/card labels, >= 22px footer, across all presets.
- Export (`src/lib/canvas/exporter.ts`, `singleSlideVideoExporter.ts`): JPG 1080x1920 Q95, single-slide `.mp4`/`.webm`, clipboard, and 5-in-1 ZIP (`slide1.jpg`..., `caption-bilingual.txt`, `caption.txt`, `first_comment.txt`, `short_caption.txt`, `carousel-manifest.json`, `post_metadata.json`, `claims_citations.txt`, `README.txt`). Pre-export QA `FAIL` and Platform Risk `BLOCK` block export unless overridden in **Caption & QA**; creator attribution renders on CTA/single-slide footer. Batch/contact-sheet loops yield with `setTimeout(0)`.
- `ContactSheetModal` previews 270x480; downloaded sheet is JPG Q95.
- Vite: `DISABLE_HMR=true` disables HMR + file watching (intentional for agent/edit environments; Playwright sets it). JSON body limit `4.5mb`; CORS never `*`.
