# AGENTS.md

## Quick facts
- React 19 + TypeScript, Vite 8, Tailwind CSS v4, Express (`server.ts` + `api/index.ts`), `@google/genai`; single package (package name `marrok-content-studio`), no workspaces.
- Path alias `@/*` -> repo root (tsconfig + vite). Entry flow: `server.ts` -> `api/index.ts` + Vite middleware/static; `src/main.tsx` -> `src/App.tsx` -> Phase 1 (`src/components/AutonomousStudio.tsx`) or Phase 2 (`src/components/studio/PublishingHubWorkspace.tsx`).
- Shared domain types live in `src/types.ts`; theme tokens in `src/lib/theme/palettes.ts`; posted-history color cadence rotation in `src/lib/theme/cadenceEngine.ts`. Canvas output supports TikTok & Instagram dimensions (`tiktok-9:16`, `ig-4:5`, `ig-3:4`, `ig-1:1`, `ig-9:16`) across three first-class post formats (`PostFormat = 'carousel' | 'single' | 'reel'`).

## Commands
- `npm run dev` — Express + Vite on `http://localhost:3000` (`PORT` overrides).
- `npm run lint` — `tsc --noEmit`; `npm test` — Vitest regression suite (jsdom + RTL). `scratch/*.mjs` is local/gitignored.
- `npm run build` — production bundle -> `dist/`.
- `npm run start` — does **not** set `NODE_ENV`; without `NODE_ENV=production` it runs Vite middleware, not `dist/`. PowerShell: `$env:NODE_ENV='production'; npm run start`.
- `npm run preview`, `npm run clean` — as defined in `package.json`.
- Verify with `npm test` + `npm run lint`; run `npm run build` for bundling/import regressions.

## Source layout / gotchas
- These are barrels: `src/lib/synthesizer.ts` -> `src/lib/synthesis/`, `src/lib/canvasExporter.ts` -> `src/lib/canvas/`, `src/lib/textSanitizer.ts` -> `src/lib/text/`. Edit the modular files, not the barrels.
- `src/lib/canvas/` is the static & single-slide video render/export pipeline. `renderSlide.ts` is a pure read-only projection (do not sanitize in the draw loop); text fitting is `textLayout.ts`; safe-zone constants (`x <= 945`, `y <= 1710`) are in `constants.ts`. `layoutAwareness.ts` is the Layout Awareness Engine computing non-overlapping vertical clearances (`MIN_GAP_GRAPHIC_TO_TITLE = 44`, `MIN_GAP_TITLES = 18`, `MIN_GAP_TITLE_TO_BODY = 36`, `MIN_GAP_BODIES = 22`), baseline conversions, dynamic font scaling, ceiling compression, and `clampElementDrag()` anti-collision clamping. `layoutBounds.ts` consumes `computeSlideLayoutAwareness()` for 1:1 synchronized 1080x1920 element bounds and point hit-testing for viewport overlays. `videoFrameExtractor.ts` extracts a 2x2 keyframe storyboard JPEG (`extractVideoStoryboardDataUrl`) for Gemini Vision video analysis, and `singleSlideVideoExporter.ts` (`exportSingleSlideVideo`) muxes single-slide video posts with MARROK chrome and preserved audio into `.mp4`/`.webm`.
- `src/lib/theme/cadenceEngine.ts` is the Feed Color Cadence Engine (`analyzePostHistoryCadence`, `resolveHarmoniousPaletteWithoutRepetition`). It inspects posted Vault records (`postStatus === 'posted'`) to avoid consecutive same-color posts, surfaces a "Recommended Next Palette" in `ThemeCustomizer.tsx`, and auto-rotates palettes during AI synthesis in `AutonomousStudio.tsx`.
- `src/lib/publish/publishClient.ts` & `api/controllers/publishController.ts` power the 100% Direct API Publishing, Weekly Calendar Queue, TikTok Commercial Music Library & Cloudinary Auto-Cleanup system:
  - Signed SHA-1 Cloudinary staging (`uploadSlideToCloudinary` to `marrok_staging/*`, with automatic public HTTPS ephemeral fallback when Cloudinary secrets are absent) and post-publish cleanup (`destroyCloudinaryAsset` / `sweepExpiredCloudinaryAssets`) `+1h` after `postedAt` or scheduled `dueAt`.
  - Direct **Buffer Free GraphQL API** (`https://api.buffer.com`) dispatch for Instagram (`@marrok_org`, using `metadata.instagram.type: 'post'` for multi-slide carousels), Facebook (`Marrok (Algiers)`), and LinkedIn (`Marrok`) with a 10-post rolling queue per channel.
  - Direct **Zernio Free REST API v1** (`https://zernio.com/api/v1` + Hosted MCP `https://mcp.zernio.com/mcp`) dispatch for TikTok (`@marrokorg`, up to 35 `9:16` photo carousel slides) and Instagram failover (`@marrok_org`), with automatic dual aspect-ratio staging (`ig-4:5` `1080×1350` for IG/FB/LI + `tiktok-9:16` `1080×1920` for TikTok).
  - Live **TikTok Commercial Music Library** (`GET /api/publish/tiktok-music` -> `GET /v1/accounts/{accountId}/tiktok/commercial-music`) auto-picking trending tracks (`autoAddMusic: true` + `musicSoundInfo: { musicSoundId }`) with an interactive track picker and audio preview.
- `src/lib/motion/` is the 9:16 Motion Reel engine (ported from `abdomarrok/motion-reel` and fused with MARROK's slide chrome):
  - `base.ts`: Damped harmonic oscillator `spring(t, k, d)`, Mulberry32 `rng(seed)`, cubic easings, `generateCues()`, and `wrapHTML()`.
  - `marrokSlideChrome.ts`: Renders MARROK's slide background, radial glow, 108px engineering grid, CAD reticles (`SYS_REF // 1080x1920.CAD_SAFE // MOTION_REEL`), authentic 32x32 glowing `drawMarrokVectorBadge` header + `MARROK` wordmark + category tag, elevated surface cards, spring-animated bilingual EN+AR slide copy, and pagination footer (`@MARROK` + active scene pill).
  - `templates/`: 4 motion templates (`marrok-slides` flagship slide deck reel, `kinetic-text`, `brand-intro`, `product-showcase`).
  - `sfxSynthesizer.ts`: 48kHz procedural sound synthesizer (`click`, `pop`, `thump`, `whoosh`) and 16-bit PCM WAV encoder.
  - `carouselToReelConverter.ts` & `videoExporter.ts`: 1-click conversion from carousel/single-slide to animated scenes, plus browser `MediaRecorder` + `AudioContext` muxed video export (`.webm`/`.mp4`), `.wav` export, and standalone `.html` export.
- `src/components/studio/` holds the viewport, navigator, inline editor, archetype controls, export bar, `PublishingHubWorkspace.tsx` + `PostManagerPanel.tsx` (consolidated Phase 2 `2. Publish & Posts (N)` workspace with 2 tabs: **Publish Active Post** and **Posts & Calendar** featuring `List`, `Calendar`, and `Bulk Schedule` views), and `src/components/studio/motion/` (`MotionReelViewport`, `MotionReelInspector`, `MotionExportModal`). `ViewportCanvas` renders instantly on slide/archetype changes, debounces text edits 150ms, and features dynamic bounding boxes with bidirectional selection sync to `InlineSlideEditor`, collision-clamped dragging, and keyboard micro-nudging.
- `api/index.ts` is a small Express app with startup env config (`api/config.ts`), security headers, rate limiting, and `4.5mb` JSON limit; routes live in `api/controllers/` (`generateController.ts`, `imageController.ts`, `postsController.ts`, `publishController.ts`, `proxyController.ts`, `mediaController.ts`), prompts/schema in `api/prompts/`, shared catalogs in `api/constants.ts`. Brand icons are shared via `src/lib/techLogos.ts`; canvas glyphs via `src/lib/icons.ts`. `src/components/studio/IconThumbnail.tsx` provides dual-rendering (`getIconDisplayName`, `<IconThumbnail />`) bridging `ICONS_REGISTRY` vector SVGs and `TECH_ICONS_LIST`/CDN URLs so editor controls match canvas projections 1:1.
- Vercel rewrites `/api/*` to `/api/index` (`vercel.json`); `api/index.ts` restores the real path from `x-matched-path`/`x-forwarded-uri`. Preserve this when changing routing.
- `specs/*.md` is useful design context; see `docs/AUDIT.md`, `docs/ARCHITECTURE.md`, and `docs/ADR/*` for current architectural decisions. Trust `server.ts`, `api/*`, and `src/lib/*` as source of truth.

## AI generation, Publishing & Multi-Key / Free Backup Cascade
- `.env`: `DATABASE_URL` (Neon PostgreSQL Serverless connection string for persistent cloud vault storage), `GEMINI_API_KEY`, `GEMINI_API_KEY_BACKUP` (or `GEMINI_API_KEY_2`), `GEMINI_API_KEYS` (comma-separated pool), `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`, `BUFFER_API_KEY`, and `ZERNIO_API_KEY`. Custom client Gemini keys are accepted via `x-gemini-key`, `x-gemini-api-key`, `x-gemini-key-backup`, or body `apiKey` / `backupApiKey`; the client stores primary and backup keys in `localStorage` (`marrok_custom_gemini_key`, `marrok_custom_gemini_key_backup`).
- `api/db/postgres.ts`: Serverless PostgreSQL layer (`pg.Pool`, SSL enabled, connection pooler) storing posts in `saved_posts` with `JSONB` slide decks, relational indexing (`post_status`, `scheduled_for`, `updated_at`, `title_signature`), idempotent schema init, and atomic upserts (`ON CONFLICT (id) DO UPDATE`) eliminating duplicate drafts across multi-device sessions and serverless restarts. Gracefully falls back to local file storage and Browser IndexedDB when offline.
- `getGeminiKeyPool(req)` (`api/config.ts`) builds a deduplicated ordered key pool (`client primary` -> `client backup` -> `server primary` -> `server backup` -> `GEMINI_API_KEYS`).
- `POST /api/generate` model cascade (`GEMINI_GENERATION_MODELS` configurable): bounded within a 45s budget using `AbortSignal.timeout()`. Iterates through the Gemini key pool (grounded attempt when prompt <= 200 chars + ungrounded schema attempts). If all Gemini keys fail or hit quota (`429`), cascades to zero-key free AI backup (`generateCarouselWithFreeBackup` in `api/freeAiFallback.ts` via Pollinations OpenAI-compatible endpoint when `FREE_BACKUP_AI_ENABLED !== 'false'`), and finally local `synthesizeCarousel()` (`engine: 'offline-synthesizer'`) with no 5xx, setting `X-Marrok-Engine`/`X-Marrok-Model`.
- `POST /api/generate-image` (`GEMINI_IMAGE_MODELS` configurable): defaults to 9:16 / 1K and supports image editing with `inlineData` + text (`<= 4 MB` validated). Pass only `imageConfig` (never `responseMimeType`/`responseSchema`). Rotates across the Gemini key pool and falls back to zero-key 9:16 Flux image synthesis (`generateImageWithFreeBackup`) for text-to-image requests when Gemini keys are exhausted.
- `runAutonomousPipeline` deliberately applies only `sanitizeFullCarousel()` to authentic AI output; the full character-limit fitting, pacing, and QA rewrite runs only for the offline fallback. Do not "fix" AI copy unless asked.
- Fallback enrichment: `balanceCarouselVisualPacing()` (`src/lib/synthesis/pacing.ts`) prevents adjacent/repeated diagram variants across 9 schematics (`topology`, `stack`, `isolation`, `takeaway`, `scatter`, `graph`, `clusters`, `split`, `features`) and fills missing nodes/edges/footer; `seedSlideArchetypeData()` (`src/lib/synthesis/archetypes.ts`) fills fields when switching archetypes. `condenseCarouselToSingleSlide()` (`src/lib/synthesis/singleSlideCondenser.ts`) condenses an 8-slide deck into a 1-slide infographic poster with 3 bilingual takeaways.

## Content / export conventions
- Post formats: `carousel` (3–10 slides), `single` (1-slide Infographic Poster, Standard Archetype, Standalone Full-Bleed Meme via `standaloneMeme: true`, or Single-Slide Video with preserved audio), and `reel` (9:16 animated Motion Reel).
- Slide types: `hub`, `row`, `number`, `metric`, `code`, `compare`, `image`, `cta`. Keep bilingual `en*`/`ar*` fields populated (unless `standaloneMeme` is active on an `image` slide, which hides bottom copy and expands the visual frame to `h = 1260`). Carousel QA limits are in `src/lib/qaChecks.ts` (`enTitle` 45, `arTitle` 40, `enBody` 140, `arBody` 150). Platform safety checks are in `src/lib/riskChecks.ts` (`PASS` / `WARN` / `BLOCK`). Mobile typography floor $\ge 26\text{px}$ is enforced in `renderSlide.ts`.
- Static & Single-Slide Video Export via `src/lib/canvas/exporter.ts` & `singleSlideVideoExporter.ts`: single JPG (1080x1920 Q95), single-slide `.mp4`/`.webm` video (with MARROK chrome + audio), clipboard, and a 5-in-1 ZIP bundle (`slide1.jpg`..., `caption-bilingual.txt`, `caption.txt`, `first_comment.txt`, `short_caption.txt`, `carousel-manifest.json`, `post_metadata.json`, `claims_citations.txt`, `README.txt`). Pre-export QA (`FAIL`) and Platform Risk (`BLOCK`) gates block export unless explicitly overridden in the **Caption & QA** tab; creator attribution is rendered on the CTA slide (or single-slide footer). Batch/contact-sheet loops yield with `setTimeout(0)`.
- Consolidated Publish & Posts Hub (`PublishingHubWorkspace.tsx` & `PostManagerPanel.tsx`): accessible via the top header phase switcher (`1. Create Studio` ↔ `2. Publish & Posts (N)`). Stages `4:5` (IG/FB/LI) and `9:16` (TikTok) slide JPEGs, dispatches IG/FB/LI via Buffer GraphQL API and TikTok/IG via Zernio REST API v1 with trending TikTok Commercial Music (`autoAddMusic` + `musicSoundInfo`), manages post lifecycles (`reschedule`, `unschedule`, `cancelAndDelete`), and automatically cleans up staged Cloudinary images `+1h` after publication.
- Motion Reel Export via `src/lib/motion/videoExporter.ts`: renders 1080x1920 @ 30fps or 60fps with mixed 48kHz procedural SFX (`WebM` / `MP4`), standalone 16-bit PCM `.wav` audio track, and self-contained `.html` animation file.
- `ContactSheetModal` previews at 270x480; the downloaded contact sheet is JPG Q95.
- Vite: `DISABLE_HMR=true` disables HMR and file watching (intentional for agent/edit environments). CORS respects `ALLOWED_ORIGIN`; JSON body limit is `4.5mb`.
- TS: `moduleResolution: bundler`, `allowImportingTsExtensions`, `noEmit`, `jsx: react-jsx`. `.npmrc` sets `legacy-peer-deps=true`; `package-lock.json` is the single lockfile.
